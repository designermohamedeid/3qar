# Dara: Real Estate WordPress Theme

A fast, bilingual (Arabic RTL / English LTR) real estate WordPress theme by [Mansoura Host](https://mansourahost.com).

| Folder | Contents |
| --- | --- |
| `dara/` | The theme |
| `dara-core/` | The required plugin: properties, projects, agents, search, leads, blocks and the demo importer |
| `dara-child/` | Child theme |
| `documentation/` | User guide (English) and licensing |
| `store-assets/` | Marketplace images: thumbnail, preview and screenshots |
| `bin/package.sh` | Builds the sale package in `dist/` |

Build the package:

```sh
sh bin/package.sh
```
