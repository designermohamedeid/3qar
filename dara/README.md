# قالب دارة العقاري — Dara Real Estate

قالب ووردبريس عقاري سريع وثنائي اللغة (عربي RTL / إنجليزي LTR)، مبني على التصميم المعتمد، ويعمل مع إضافة **Dara Core** (موجودة في مجلد `dara-core/` بجانب القالب).

## التثبيت

```bash
zip -r dara.zip dara -x "dara/node_modules/*" "dara/assets/css/src/*"
zip -r dara-core.zip dara-core
```

1. **الإضافات ← أضف جديد ← رفع إضافة**: ارفع `dara-core.zip` وفعّلها.
2. **المظهر ← قوالب ← رفع قالب**: ارفع `dara.zip` وفعّله.
3. **الإعدادات ← روابط دائمة**: اختر "اسم المقالة".

## البداية السريعة: المحتوى التجريبي

بعد تفعيل الإضافة والقالب، هتظهر رسالة في لوحة التحكم. ادخل على **العقارات ← المحتوى التجريبي**، واختر لغة المحتوى (عربي أو إنجليزي)، واضغط **استيراد المحتوى التجريبي**. هيتملا الموقع بـ:
- 8 عقارات، ومشروعين، ومسوّقَين، و3 مقالات.
- صفحات: الرئيسية، والمدونة، وتواصل معنا، وأضف عقارك، والمفضلة.
- القوائم وإعدادات الصفحة الرئيسية.

الصور رسومات أصلية مرفقة مع الإضافة، فمفيش أي مشكلة حقوق. وزرار **حذف المحتوى التجريبي** بيمسح كل حاجة اتضافت بضغطة واحدة، ويرجّع إعداداتك من غير ما يلمس محتواك.

## بناء الصفحات بالبلوكات (Gutenberg)

كل أقسام الرئيسية متاحة كبلوكات في قسم **"دارة العقارية"** في محرر الصفحات، وتقدر تستخدمها في أي صفحة وبأي ترتيب:

| البلوك | الإعدادات |
|---|---|
| الواجهة والبحث | الصورة، العناوين، إظهار البحث، التبويب الافتراضي (شراء/إيجار/مشاريع)، عمليات البحث الشائعة |
| شبكة العقارات | العدد، المميزة فقط، الغرض (بيع/إيجار)، نوع العقار، إظهار روابط الأنواع وزر "عرض الكل" |
| أنواع العقارات / مشاريع المطوّرين / المسوّقون / أحدث المقالات | العناوين والعدد |
| الخدمات | قائمة خدمات تقدر تضيف فيها وتحذف وترتّب، وتختار لكل خدمة أيقونة |
| صورة وقائمة مميزات / دعوة لإجراء | الصورة والنصوص والأزرار |

- المعاينة داخل المحرر هي نفس شكل الموقع بالظبط، لأن البلوكات بتستخدم نفس قوالب الأقسام.
- أي حقل تسيبه فاضي بياخد قيمته من **المظهر ← تخصيص**.
- **أنماط جاهزة** (Patterns): "صفحة رئيسية عقارية" و"صفحة هبوط للعقارات"، تتضاف بضغطة من تبويب الأنماط.
- لو الصفحة الرئيسية الثابتة فيها بلوكات دارة، القالب بيعرضها بعرض كامل بدل أقسام التخصيص. ولو أول بلوك في أي صفحة هو "الواجهة والبحث"، الهيدر بيبقى شفاف فوقه.
- البلوكات بتترسم من السيرفر، فمفيش أي JavaScript أو CSS إضافي في الواجهة. سكربت المحرر (5KB) بيتحمّل في لوحة التحكم بس.
- استيراد الديمو بيبني الصفحة الرئيسية بالبلوكات، فتقدر تعدّلها من المحرر على طول.

## الإعداد السريع

| المطلوب | المكان |
|---|---|
| العملة، بريد استقبال الطلبات، رخصة فال، السجل التجاري، رقم التواصل الافتراضي | **العقارات ← الإعدادات** |
| العقارات (السعر، المساحة، الغرف، معرض الصور، المخططات، الفيديو، الإحداثيات، رقم ترخيص الإعلان، المسوّق) | **العقارات ← إضافة** |
| أنواع العقارات (مع أيقونة) / المدن والأحياء / المميزات | تصنيفات تحت قائمة **العقارات** |
| المسوّقون (الاسم، الجوال، واتساب، رخصة فال، الصورة، نبذة) | **العقارات ← المسوّقون**. ليهم صفحة دليل `/agents/` وصفحة لكل مسوّق فيها عقاراته ونموذج تواصل بيوصل لبريده |
| مشاريع المطوّرين (نسبة الإنجاز، جدول الوحدات، خطة الدفع، مراحل التنفيذ، البروشور) | **المشاريع ← إضافة** |
| كل نصوص وصور الرئيسية، الألوان، التواصل، الشبكات الاجتماعية، الخرائط | **المظهر ← تخصيص ← قالب دارة** |
| القوائم | **المظهر ← القوائم**: "Main menu" و "Footer: quick links" |
| صفحات جاهزة | أنشئ صفحة واختر القالب: **Contact** / **List your property** / **Favorites** / **Full width** |
| الطلبات الواردة (معاينات، اهتمام بمشروع، تواصل، أضف عقارك، النشرة) | قائمة **الطلبات** في لوحة التحكم (مع عدّاد للطلبات الجديدة + إيميل فوري) |

## المميزات

- **بحث متقدم**: الغرض، النوع، المدينة/الحي (مع اقتراحات تلقائية)، نطاق السعر والمساحة، الغرف، المميزات، الترتيب. يعمل بدون JavaScript وبروابط قابلة للمشاركة والفهرسة.
- **عرض الخريطة** في نتائج البحث بدبابيس الأسعار، وخريطة في صفحة العقار والمشروع والتواصل (OpenStreetMap مجاناً، ويمكن تغيير مزوّد الخرائط من التخصيص).
- **صفحة عقار كاملة**: معرض صور مع عارض بملء الشاشة (سحب باللمس)، المخططات بتبويبات، فيديو يُحمّل عند الضغط فقط، الأماكن القريبة، بطاقة المسوّق مع اتصال وواتساب برسالة جاهزة، نموذج طلب معاينة، بيانات الترخيص، عقارات مشابهة، مشاركة وطباعة.
- **صفحة مشروع للمطوّرين**: نسبة الإنجاز، جدول الوحدات بحالتها، خطة الدفع، مراحل التنفيذ، شارة "وافي"، نموذج تسجيل اهتمام.
- **المفضلة** بدون تسجيل دخول (تُحفظ في المتصفح) مع صفحة لعرضها.
- **SEO**: بيانات منظمة `RealEstateListing` لكل عقار ومشروع، ووصف meta تلقائي إذا لم تكن هناك إضافة SEO، ودعم Breadcrumbs الخاصة بـ Yoast و Rank Math.
- **نماذج متوافقة مع الكاش** (بدون nonce ينتهي)، والحماية من السبام بحقل فخ ووقت أدنى وحد للإرسال من نفس الـ IP.
- **ثنائي اللغة**: ترجمة عربية كاملة للقالب والإضافة، وملفات `.pot` لأي لغة أخرى، وتبديل اللغة تلقائياً مع Polylang أو WPML.
- **إمكانية الوصول**: تباين ألوان مناسب، أزرار حقيقية، تنقل بلوحة المفاتيح، وأهداف لمس بحجم 44px على الأقل.

## السرعة

| | القالب |
|---|---|
| jQuery / Bootstrap / مكتبة أيقونات | لا يوجد |
| CSS | ملف أساسي ~5.5KB (gzip) + ملف صغير للقالب الحالي فقط (1–1.7KB) |
| JavaScript | ملف واحد ~3.6KB (gzip)، يُحمّل بـ `defer` |
| الخطوط | IBM Plex Sans Arabic مستضاف محلياً، 3 أوزان، `font-display: swap`، مع preload |
| الخرائط | Leaflet يُحمّل فقط عند ظهور الخريطة على الشاشة |
| الصور | مقاسات مخصصة + `srcset` + lazy loading، مع preload و`fetchpriority=high` لصورة LCP |
| ووردبريس | تعطيل الإيموجي، وتحميل CSS المكوّنات المستخدمة فقط بدل المكتبة كاملة (~110KB) |

نتائج Lighthouse (موبايل، على سيرفر بضغط gzip وكاش): الرئيسية 97، صفحة البحث 94، صفحة العقار 98، صفحة المشروع 100. وإمكانية الوصول وSEO كلاهما 100.

**على السيرفر الحقيقي** فعّل ضغط gzip/brotli وكاش طويل للملفات الثابتة، واستخدم إضافة كاش للصفحات (LiteSpeed Cache / WP Super Cache)، وارفع الصور بصيغة WebP.

## التطوير

- مصدر الـ CSS في `assets/css/src/main.css`، و`build-css.py` بيقسّمه لحزم حسب القالب (core / home / listing / property / project / content).
- `npm install && npm run build` يقسّم الملفات ويضغط الـ CSS والـ JS (`*.min.*`).
- مع `SCRIPT_DEBUG` القالب بيحمّل الملفات غير المضغوطة.
- فلاتر للمطوّرين: `dara_home_sections` (ترتيب أقسام الرئيسية)، `dara_css_bundles`، `dara_agent`، `dara_schema`، `dara_setting`.
