# قالب الثراء العقارية – WordPress Theme

قالب ووردبريس احترافي ثنائي اللغة (عربي RTL / إنجليزي LTR) محوَّل من قالب HTML الأصلي الموجود في جذر المستودع.

## التثبيت

1. اضغط مجلد `thara` في ملف ZIP:
   ```bash
   cd /path/to/repo && zip -r thara.zip thara
   ```
2. من لوحة التحكم: **المظهر ← قوالب ← أضف جديد ← رفع قالب** وارفع `thara.zip` ثم فعّله.
3. اضبط **الإعدادات ← روابط دائمة** على "اسم المقالة" (يتم تحديث قواعد الروابط تلقائياً عند التفعيل).

## الإعداد بعد التفعيل

| المطلوب | المكان |
|---|---|
| الصفحة الرئيسية | **الإعدادات ← القراءة**: اختر "صفحة ثابتة" كرئيسية وصفحة أخرى للمقالات (الأخبار). الأقسام تظهر تلقائياً في الرئيسية. |
| القوائم | **المظهر ← القوائم**: مكان "Primary Menu" (الهيدر وقائمة الجوال، تدعم قائمة فرعية) و"Footer Quick Links". |
| كل نصوص وصور الرئيسية | **المظهر ← تخصيص ← إعدادات قالب الثراء** (الواجهة، من نحن والعدادات، الرؤية والأهداف، الخدمات، العقارات، الأخبار، بيانات التواصل، روابط التواصل، الفوتر، الألوان). |
| الشعار وأيقونة الموقع | **تخصيص ← هوية الموقع**. |
| العقارات | قائمة **العقارات** في لوحة التحكم: صورة بارزة + السعر، الموقع، المساحة، الغرف، الحالة (بيع/إيجار). مع تصنيف "أنواع العقارات". |
| الخدمات | قائمة **الخدمات**: الصورة البارزة تُستخدم كأيقونة، والترتيب من خانة "الترتيب". |
| صفحة اتصل بنا | أنشئ صفحة واختر قالب **Contact**، وضع كود نموذج (Contact Form 7 / WPForms) في المحتوى، وكود خريطة جوجل من التخصيص. |
| النشرة البريدية | تعمل مباشرة (تُحفظ في **أدوات ← مشتركو النشرة البريدية** وتصل رسالة للمدير)، أو ضع shortcode / رابط Mailchimp من التخصيص. |

## اللغات

- كل النصوص قابلة للترجمة (text domain: `thara`)، مع ترجمة عربية كاملة في `languages/ar.po` و`ar.mo`، وملف `thara.pot` لأي لغة أخرى.
- اتجاه الصفحة (RTL/LTR) وملفات Bootstrap RTL والأسهم واتجاه السلايدر تتغير تلقائياً حسب لغة الموقع.
- لموقع بلغتين: فعّل **Polylang** أو **WPML** وسيظهر زر تبديل اللغة تلقائياً في الهيدر وقائمة الجوال. بدونهما يمكن وضع رابط النسخة الأخرى يدوياً من التخصيص ← عام.

## هيكل القالب

```
thara/
├── style.css, functions.php, screenshot.png
├── header.php, footer.php, front-page.php, index.php, page.php, single.php,
│   archive.php, search.php, 404.php, comments.php, searchform.php, sidebar.php
├── archive-thara_property.php, single-thara_property.php, taxonomy-property_type.php
├── archive-thara_service.php
├── page-templates/   (contact.php, full-width.php)
├── template-parts/   (header/, home/, content/, footer/)
├── inc/              (setup, enqueue, menus, post-types, customizer, newsletter, template-tags)
├── assets/css        (main.css = تصميم القالب الأصلي، theme.css = صفحات ووردبريس)
├── assets/js, assets/fonts, assets/webfonts, assets/images
└── languages/        (thara.pot, ar.po, ar.mo)
```

## ملاحظات

- خط **SST Arabic** المستخدم في التصميم الأصلي تجاري ولم يكن موجوداً في المشروع، فتم استخدام خط **Tajawal** المجاني (مستضاف داخل القالب). إذا كان لديك ترخيص SST Arabic عرّف `@font-face` باسم `sa` في CSS إضافي وسيُستخدم تلقائياً.
- يمكن تغيير اللونين الذهبي والداكن من التخصيص ← عام (متغيرات CSS: `--thara-primary` و `--thara-dark`).
- أنواع المحتوى (العقارات والخدمات) مسجلة داخل القالب لتسهيل التسليم؛ عند تغيير القالب لاحقاً يبقى المحتوى في قاعدة البيانات ويمكن نقل `inc/post-types.php` لإضافة صغيرة.
